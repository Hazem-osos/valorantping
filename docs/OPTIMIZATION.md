# Optimization Center

Phase 2 will not change Windows unless you confirm an evidence-backed action.

## Applyable surfaces

| Action | Evidence required | Privilege | Backup |
| --- | --- | --- | --- |
| High Performance power plan | Local gateway instability or upload-linked spikes | Standard user | Previous `powercfg` scheme GUID |
| NIC “allow computer to turn off this device” | Local gateway / hop-1 issues | Administrator | Per-adapter previous value |

Guidance-only (never applied): pause uploads, router SQM/QoS, Ethernet duplex check, ISP/Riot path explanation.

## Forbidden

DNS, MTU, routing, firewall, registry, `netsh int tcp`, Vanguard, VALORANT. No silent adapter speed/duplex writes.

## After a change

The app never claims the ping improved. Run the 15-minute test and compare overlay p95 to the baseline.
